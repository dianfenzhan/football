# 首页「已报名」状态显示

## Context

用户报名下一场活动后返回首页，按钮仍显示「⚽️ 去报名」，造成困惑（已报过名还被引导报名）。根因：`homeSummary` 云函数不接收 openid，返回的 `nextActivity` 里没有当前用户的报名状态，首页无从得知。

用户已决策：已报名后按钮区显示**浅绿状态条**「✓ 已报名 · 队名」（与活动页已报名态同款），卡片本身仍可点进活动页（查看/取消在活动页操作）。

## 改动

### 1. 云函数 [index.js](file:///Users/zhoukaijie/selfProject/football/codeBase/cloudfunctions/api/index.js)

- 分发处（L37）：`homeSummary(event)` → `homeSummary(OPENID, event)`
- `homeSummary`（L381）内：拿到 `next` 后，若存在则查一次当前用户报名：

```js
let signedUp = false
if (next) {
  const mine = await db.collection('signups')
    .where({ activityId: next._id, _openid: openid }).limit(1).get()
  signedUp = mine.data.length > 0
}
```

- `nextActivity` 返回值带 `signedUp` 布尔（无 next 时 `nextActivity: null` 不变）

队名不需要后端带：首页已并发调 `me`（拿 isAdmin），`me.user.teamId` + 返回的 `teams` 前端可拼。

### 2. 首页前端

- [home.js](file:///Users/zhoukaijie/selfProject/football/codeBase/miniprogram/pages/home/home.js)：`load()` 里把 `activity.signedUp` 透传进 `next`，并从 `profile.user.teamId` + `teams` 算出 `myTeamName` 存 data
- [home.wxml](file:///Users/zhoukaijie/selfProject/football/codeBase/miniprogram/pages/home/home.wxml)：

```xml
<view wx:if="{{next.signedUp}}" class="signed-banner">✓ 已报名 · {{myTeamName}}</view>
<button wx:else class="btn hero" data-id="{{next._id}}" bindtap="open">⚽️ 去报名</button>
```

- [home.wxss](file:////Users/zhoukaijie/selfProject/football/codeBase/miniprogram/pages/home/home.wxss)：加 `.signed-banner` 样式（从 activity.wxss 复制：#e3efe9 浅绿底、深绿字、同样圆角/行高，与 hero 按钮等宽）

### 3. Smoke 检查 [smoke-test.js](file:///Users/zhoukaijie/selfProject/football/codeBase/scripts/smoke-test.js)

smoke 创建的活动 `startTime = now + 60s`，就是断言窗口内的 nextActivity：

- signup 成功后（L140 附近）：调 `homeSummary`，断言 `nextActivity.signedUp === true`，PASS 项名 `homeSummary signedUp true`
- cancelSignup 后（约 L230 附近）：断言 `signedUp === false`，PASS 项名 `homeSummary signedUp false`

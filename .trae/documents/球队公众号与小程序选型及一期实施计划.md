# 球队公众号与小程序选型及一期实施计划

## Context（背景与结论）

**需求**：业余养生球队（约 150 人群），需要：球队动态展示、活动报名、收费、比分记录等功能。

**核心结论：公众号和小程序不是二选一，而是分工互补**：

| 载体 | 定位 | 说明 |
|---|---|---|
| **公众号（订阅号）** | 内容门户：球队动态、活动回顾、照片 | 个人身份免费注册，零开发，当天可上线发文章 |
| **小程序** | 互动工具：报名、记分、费用登记 | 需开发，但球员扫码即用、体验远超接龙/表格 |

建议**两个都做**：先用订阅号解决「动态展示」（零成本），再做小程序解决「报名/记分」。公众号菜单可挂小程序入口互相导流。

**关键约束（已与你确认）**：
- 仅个人身份主体 → **无法开通微信支付**，收费先做「人工标记缴费」方案（微信转账 + 队长标记），未来升级个体工商户后再接支付
- 后端用**微信云开发**：免服务器、免域名备案，自带数据库/云函数/云存储（注意：云开发环境为付费服务，基础套餐约 ¥19.9/月）

## 开源调研结论：没有可直接拿来用的成熟项目

通过 GitHub API 多轮搜索（"球队管理"、"约球 小程序"、"球队 微信"、"篮球队 管理"）：

- 搜索结果绝大多数是**毕设营销仓库**（源码需联系作者付费购买，基于 SSM/SpringBoot + MySQL，与云开发方案不匹配）
- 最接近的是 [HeXavi8/Bugu-Sport](https://github.com/HeXavi8/Bugu-Sport)（不咕约球，MIT 协议，仅 18 star）：面向校园约球场景（学生认证、约赛、野球），与"单球队内部管理"场景差异大，改造成本不低于自研
- 其余约球类项目 star 数 ≤ 18，无维护、质量无保障

**结论：放弃"抄一份"路线，改为基于微信官方云开发模板自研**。核心功能（报名、记分）本质是简单 CRUD，对 IT 程序员工作量可控，且完全掌控数据与后续迭代。

## 技术方案

**前端**：微信原生小程序（微信开发者工具直接创建云开发模板，与云开发集成零摩擦）
**后端**：微信云开发（TCB）— 云数据库 + 云函数 + 云存储
**目录**：代码放在现有 `codeBase/` 下

### 数据模型（云数据库集合）

```js
users         // 队员：_openid, name, avatar, phone, position, jerseyNumber, isAdmin
activities    // 活动：title, type(训练/比赛), startTime, location, feePerPerson, maxSignups, deadline, createdBy, status
signups       // 报名：activityId, _openid, userName, status(报名中/已取消), paid(未缴/已缴/无需), createdAt
matches       // 比赛：activityId, opponent, ourScore, theirScore, date, summary
match_events  // 赛事事件：matchId, playerId, eventType(进球/助攻/黄牌), minute
```

### 功能分期

- **P0（一期，本次实施）**：
  - 微信授权登录 + 队员档案（姓名、位置、号码）
  - 活动发布（队长）+ 报名/取消报名 + 报名名单头像墙
  - 「我的」页：我报名的活动、缴费状态展示
- **P1（二期）**：比分录入、射手榜/出场榜、活动回顾图文
- **P2（三期）**：费用统计报表；升级个体工商户后接微信支付；关联公众号

## 实施步骤

1. **注册账号**（你手动操作）：
   - 小程序：mp.weixin.qq.com 用个人身份注册，获取 AppID
   - 订阅号：同站点注册个人订阅号（发球队动态用）
2. **开通云开发**：微信开发者工具 → 云开发控制台，创建环境（基础套餐），记录环境 ID
3. **初始化项目**：微信开发者工具导入云开发模板到 `codeBase/`，填入 AppID 与环境 ID
4. **P0 开发**（由我在 codeBase 中实现）：
   - 页面：首页（活动列表）、活动详情（报名）、我的、管理员创建活动页
   - 云函数：报名/取消（含名额校验与并发安全）、活动 CRUD
   - 数据库权限规则：报名记录仅本人可写，活动仅管理员可写
5. **体验版验证**：上传体验版 → 生成二维码发到球队群 → 收集反馈
6. **提交审核上线**（个人小程序审核通常 1-7 天）

## 验证方式

- 微信开发者工具模拟器 + 真机预览走通：登录 → 创建活动 → 第二个账号报名 → 名单更新 → 取消报名
- 云开发控制台核对 signups/users 集合数据正确性
- 报名满员后再报名应被拒绝（名额校验）

## 明确不做的事（本期）

- 微信支付（个人主体不可用，用人工标记缴费替代）
- 公众号开发（只需注册后发图文，无代码）
- 多球队/约战等平台化功能

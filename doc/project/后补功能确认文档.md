# 后补功能确认文档

状态：待确认。确认前不动代码。

原则：尽量一键搞定。每队后补最多 3 人；有人退出，后补第 1 位立刻补上，并给本人发订阅消息（已授权时）。新建/改名额不加任何后补配置。

---

## 用户怎么用

| 情况 | 大按钮 | 点下去 |
| --- | --- | --- |
| 本队有空 | ⚽️ 立即报名 | 直接报本队 |
| 本队满、后补未满 | 排本队后补 | 直接进后补，并请求一次订阅授权 |
| 本队满、后补满、另一队有空 | 去另一队报名 | 确认一句后报另一队 |
| 都满 | （点了 toast） | 「暂时报不上」 |

「去另一队」确认框：「本场先跟「某某队」踢。你的主队资料不会改。」→「就这样」/「再想想」。

不弹三选一面板。常见路径只有一刀：有空就报，满了就排后补。

第一次注册并报名：本队有空 → 注册完直接报上；本队满 → 注册完再走上面同一套按钮逻辑。

| 状态条 | 操作 |
| --- | --- |
| ✓ 已报名 · 本场队名 | 取消报名 |
| ⏳ 后补中 · 队名（第 N 位） | 退出后补 |

后补中想去另一队：先退出后补，再点大按钮。名单每队下显示后补（最多 3 人，第 1 / 2 / 3 位）。

首页：未报名「去报名」；已报名「✓ 已报名 · 队名」；后补中「⏳ 后补中 · 队名」。

分享：正选满且后补未满时写「人满了，还可以排后补」。

管理员：界面与现在相同，不做「调后补顺序」「指定补入」。名额改大时，多出的位子按后补顺序自动补上。

---

## 规则（实现）

- 同一人同一场一条记录：正选或后补，不能两队同时。
- 正选取消 → 后补第 1 位立刻变正选并发订阅消息；无后补则空位谁都能报。
- 后补退出 → 后面位次前移。已开始不能报/后补/取消。出勤和进球助攻只认正选。
- 订阅消息只做「后补→正选」；未授权不影响升正选。报名/取消走事务。

数据：`signups` 增加 `status`（`signed` | `waitlist`）、`waitlistOrder`、`waitlistedAt`。常量 `WAITLIST_LIMIT = 3`。

云函数：`signup` 支持后补与报另一队；`cancelSignup` 取消后立刻升后补并尝试发订阅；`updateQuota` 扩容立刻补位；详情/列表/首页带回后补状态；删活动清后补。

---

## 怎样算做完

- 有空一键报；满了未满后补一键排后补；后补也满才出现「去另一队」。
- 后补满 3 不能再排；正选退出后第 1 位立刻进正选，授权后收到订阅消息。
- 无三选一面板；无管理员调序。冒烟/回归补用例后对齐文档。

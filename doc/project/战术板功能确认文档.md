# 需求：活动场次战术板 · 擅长位置 · 自由拖动

状态：已交付并对齐。实现落点：`football` 小程序（炯路 / 老聚三）。

原则：战术板服务「排阵 + 发群」，不改报名数据。只在活动详情页提供战术板（位于报名名单与记录数据之间）。不做首页球队常备板。

---

## 0. 范围

| | 活动场次战术板 |
| --- | --- |
| 入口 | 活动详情页内嵌卡片（报名名单下、记录数据上） |
| 展示谁 | 顶部**切换队伍**看各组板（分队两队；联合另含联队）；默认本场所在队（未报名则主队）；当前组正选出勤前 **8** 上场，其余在**轮换** |
| 谁可改 | **仅本场正选**；正选可改**任意组**战术板（含拖上下场）。后补/未报名可看、可导出，不可拖动/保存 |
| 不做 | 轮换姓名搜索 |
| 场上 | 硬顶 8；长按约 150ms 自由拖；可拖到轮换下场，可从轮换拖上场 |
| 持久化 | `tactics_boards`（`scope: 'activity'`）；本场每组至多 1 块；懒创建 |
| 海报 | 活动标题/时间/地点 + 队名 + 当前站位 |

---

## 1. 交互

报名/取消后页面刷新会立刻重算各组战术板：未保存按该组正选出勤前 8；已保存则在册保留、离队撤下并提示。

每组底部：「保存阵容」+「保存到相册」「分享战术图」。

删活动级联删本场战术板。

---

## 2. 擅长位置

前锋 / 中场 / 后卫 / 门将。建档可填，缺省随机。管理员可改他人。默认排阵按位置填 3-2-2。

---

## 3. 明确不做

- 首页球队常备板
- 「换回常来的 8 人」
- 离开时未保存提示
- 与报名当场自动加人
- 人人改他人擅长位置（仅管理员）

## 做什么

这一期只做一个微信小程序，给两支球队共用：

- jiong 路青少年
- 浦东老聚三

球员用它报名。管理员用它改名额、记每轮比分、记本场进球和助攻。所有人可以按月、季、年查进球和助攻。

活动建好后，管理员把小程序卡片发到两个微信群。不做消息推送。

## 不做什么

- 不注册订阅号，不发文章。以后要留赛后图文，再单独注册，不影响这个小程序。
- 不收费，不做缴费标记，不接微信支付。
- 不记录每 15 分钟谁换上、谁换下。轮换只作为比赛方式，一期只记每一轮的比分。
- 进球和助攻不挂到某一轮，只挂在整场活动上。
- 不自建服务器，不装 MySQL，不部署 GitHub 上的现成项目。

## 报名

- 队员第一次打开小程序时选择所属球队，并填写姓名。
- 新建活动时，每队名额默认 11，两队可以分别改。
- 已经有人报名之后，仍然可以改名额。新名额不能小于该队当前已报名人数。
- 满员后不能再报。本人可以取消，取消后名额马上空出来。
- 每轮比分按这两支球队对踢来记：jiong 路青少年 vs 浦东老聚三。

## 比赛和统计

- 一场活动下面可以加多轮。每一轮记双方进球数，按添加顺序排列。
- 不核对是不是刚好隔了 15 分钟。
- 进球、助攻只能记给本场已经报名的球员。同一人一场可以有多个进球和多个助攻。
- 只有管理员能改活动、名额、比分、进球和助攻。
- 统计按活动开始时间归入月、季、年，汇总每人的进球和助攻，可以按球队筛选。

## 技术方案

原生微信小程序 + 微信云开发。代码放在 `codeBase/`。

不用租服务器，也不在自己的机器上装数据库。上传都在微信开发者工具里完成：

- 页面上传为小程序体验版，审核通过后发布。
- 云函数点「上传并部署」，跑在微信的环境里。
- 在云开发控制台建立下面这些集合，并写好权限。这是微信的文档数据库，不是 MySQL。

| 集合 | 内容 |
| --- | --- |
| teams | 两支球队 |
| users | openid、姓名、所属球队、是否管理员 |
| activities | 标题、开始时间、地点、状态 |
| quotas | 某场活动里某队的名额 |
| signups | 谁报名了哪场、哪一队 |
| rounds | 某一轮双方比分 |
| contributions | 某场活动里某人的进球数、助攻数 |

云函数负责：报名和取消（校验该队名额）、改名额（不能低于已报名人数）、记轮次比分、改本场进球助攻、按月季年汇总。

报名记录只有本人能改自己的报名状态。活动、名额、比分、进球助攻只有管理员能写。

云开发环境挂在小程序账号下。未发布时可以先用免费环境。正式发到群里之前，转基础套餐 19.9 元/月。免费环境在小程序发布后第 15 天到期，到期不续费，数据会被清掉。

## 怎样算做完

用两个微信号走通：

- 分别加入两队并报名。
- 一队报满 12 人后，再报名被拒绝。
- 管理员把该队名额改成 14 后，可以再报。
- 名额不能改到低于已经报名的人数。
- 管理员记下至少两轮比分，给已报名球员记进球和助攻。
- 月度查询里的进球、助攻和这场记录一致。

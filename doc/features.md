# 功能

以代码为准。页面入口看 `codeBase/miniprogram/app.json` 和各页 `call(...)`。云函数 action 看 `codeBase/cloudfunctions/api/index.js` 的 `exports.main`。对齐用 skill `doc-anchored`。

两支球队：`team_jiong` jiong 路青少年，`team_pudong` 浦东老聚三。

底部导航 5 项：首页、活动、数据、球员、我的。

## 页面

| 页面 | 路径 | 调用 | 行为 |
| --- | --- | --- | --- |
| 首页 | `pages/home/home` | `homeSummary`、`me` | 顶部品牌头（⚽️ 徽标 + 队名 + 副标语）。还没开始的最近一场以深绿渐变大卡展示：右上角金色倒计时徽章（还有 N 天/N 小时/已开赛）、📅 日期时间、📍 地点、两队报名进度条。已报名该场时按钮区显示浅绿状态条「✓ 已报名 · 队名」，未报名显示深绿大按钮「⚽️ 去报名」，均直达/可点进该活动页。没有未开始活动时显示空态卡（🥅 + 「最近没有球局」），管理员额外显示同款 hero「＋ 新建活动」按钮，普通球员无按钮 |
| 活动 | `pages/activities/activities` | `me`、`listActivities`、`deleteActivity` | 按开始时间倒序，每页 10 条，滑到底再取下一页。管理员右下角常驻深绿圆形悬浮「＋」新建活动。管理员左滑一条活动后点「删除」，确认后删除整场并重新加载列表 |
| 新建 | `pages/activity-edit/activity-edit` | `me`、`createActivity` | 标题默认为「养生球」，可以改。地点、时间。地点默认「界龙足球基地（界绿路 88 号）」。时间默认离现在最近、且还没到的周三 20:00。两队人数滚动选择，1 到 30，默认 12。非管理员不可新建。创建人不自动报名。创建成功后进入活动页并弹出分享 |
| 活动页 | `pages/activity/activity` | `activityDetail`、`signup`、`cancelSignup`、`saveProfile`、`updateQuota`、`saveRound`、`deleteRound`、`deleteContribution`、`setContribution`、`setAbsent` | 未开始时顶部是报名操作区（滚动时常驻屏幕上方），三态：未注册=深绿大按钮「⚽️ 立即报名」+引导小字，点开注册弹层（chooseAvatar 一键带入微信头像、nickname 输入框快捷填昵称、选球队），保存即注册并自动报名；已注册未报名=大按钮「⚽️ 立即报名·队名」；已报名=浅绿状态条「✓ 已报名·队名」，右侧内嵌白色「取消报名」胶囊按钮（带按压反馈），点击后确认弹窗二次确认再取消。「📤 邀请队友」全员可见，分享文案带标题、时间、地点和剩余名额（满员时「已满员，可先围观」）。未开始只显示报名相关内容：活动信息、两队报名名单（每队名下一行「已报 N / M」，满员带「已满」；管理员点名额数字弹滚轮修改）。已开始后报名区隐藏，提示「活动已开始，报名已截止」，全员可见本场数据和每轮比分，管理员多出「记录数据」（选已建档队员，进球助攻滚轮 0 到 20，出勤正常或鸽子；行内直接改；左滑删除确认；选鸽子时进球或助攻不为 0 会提示且不能保存；不要求该队员已报名）。名单和数据行显示头像，无头像按姓名首字色块。数据行用 ⚽️ 进球、👟 助攻、🐦 鸽子。活动已删除时显示「活动不存在或已取消」兜底。创建人从新建页进来时弹出分享 |
| 数据 | `pages/stats/stats` | `homeSummary` | 顶部时间跨度切换：近 3 个月、近半年、近 1 年、近 2 年、近 3 年，默认近 3 个月。⚽️ 进球、👟 助攻、🐦 鸽子三榜各前 10，行含名次、头像（无头像首字色块）、姓名、球队、数值。单场数据从活动 tab 点进活动页查看 |
| 我的 | `pages/me/me` | `me`、`saveProfile`、`listMembers`、`setAdmin` | chooseAvatar 按钮同步微信头像、nickname 输入框快捷填微信昵称、球队选择。保存时头像有变更先传云存储再存 fileID，成功提示「已同步」，并同步到该用户所有报名和数据记录。保存前校验昵称非空，失败（含昵称为空、球队非法、头像上传失败）都弹 toast 提示原因，不再静默。头像 fileID 加载失败时回退首字色块。授权人可开关其他人的管理员 |
| 球员 | `pages/players/players` | `me`、`listPlayers` | 胶囊切换两支球队，默认选自己球队且排在左边，没填资料默认 jiong 路。每行头像（无头像首字色块）+姓名，管理员排最上面，其余按注册时间倒序。空态提示「该球队还没有队员」 |

## 云函数 action

| action | 谁可以 | 行为 |
| --- | --- | --- |
| `me` | 已登录 | 当前用户和两支球队。若还没有授权人，最早的管理员成为授权人 |
| `saveProfile` | 已登录 | 保存姓名、球队和头像（`avatarUrl` 可空：传空串清除，不传不动旧值），并改写该用户已有报名和进球助攻缺勤记录上的姓名、球队、头像。第一个建档的人是管理员且是授权人。姓名为空或球队非法则失败 |
| `listMembers` | 授权人 | 成员列表 |
| `listPlayers` | 已登录 | 全部队员列表，按注册时间倒序，上限 200 |
| `setAdmin` | 授权人 | 开关他人管理员。不能改授权人自己 |
| `listActivities` | 已登录 | 活动按开始时间倒序，每页 10 条，传 `page` 翻页，返回 `hasMore`。带每队名额和已报名人数 |
| `deleteActivity` | 管理员 | 删除活动，并删除该场的名额、报名、轮次、进球助攻缺勤。缺少活动或记录不存在则失败。非管理员失败 |
| `activityDetail` | 已登录 | 一场的名额、报名（每条带是否管理员、冗余姓名和头像）、轮次、进球助攻缺勤（冗余姓名和头像）、当前用户。管理员额外得到已建档队员 `members`。缺少活动则失败 |
| `createActivity` | 管理员 | 标题、地点、开始时间、两队人数。每队 1 到 30，缺省 12。标题、地点或时间为空则失败 |
| `updateQuota` | 管理员 | 改一队人数。活动已开始、人数不在 1 到 30、或低于该队已报名人数则失败 |
| `signup` | 已填资料 | 用自己的球队报名。活动已开始、重复报名、满员则失败 |
| `cancelSignup` | 已登录 | 取消自己这场的报名。活动已开始或未报名则失败 |
| `saveRound` | 管理员 | 新增或修改一轮比分，jiong 对浦东，0 到 99 |
| `deleteRound` | 管理员 | 按 `roundId` 删除一轮。缺少轮次或记录不存在则失败。非管理员失败 |
| `deleteContribution` | 管理员 | 按 `contributionId` 删除一名队员这场的进球、助攻和出勤。缺少记录或记录不存在则失败。非管理员失败 |
| `setContribution` | 管理员 | 给已建档队员记进球和助攻，0 到 99。不要求已报名。找不到队员则失败。已经是鸽子时，进球或助攻不为 0 则失败 |
| `setAbsent` | 管理员 | 给已建档队员记出勤：鸽子或正常。不要求已报名。找不到队员则失败。鸽子时进球或助攻不为 0 则失败 |
| `stats` | 已登录 | 按 `month`、`quarter` 或 `year` 汇总进球、助攻、缺勤，行内带头像。可传 `teamId`。页面不直接调用，冒烟脚本用它做统计断言 |
| `homeSummary` | 已登录 | 开始时间晚于现在的最近一场（带 `signedUp`：当前用户是否已报名该场，按 `status: 'signed'` 判断），以及 `span`（`3m` `6m` `1y` `2y` `3y`，非法值也按 `3m`）内进球、助攻、鸽子各前 10（带头像）。首页只取最近一场，数据页用榜单 |
| `testSetup` | 回归测试 | 仅当云函数配置了 `REGRESSION_KEY` 环境变量且入参匹配才执行，否则拒绝。`op` 支持 `ping`/`snapshot`/`unregister`/`restore`/`setRole`/`createFake`/`fakeSignup`/`removeFake`，供回归脚本切换身份、造假队员（固定 openid `regression_fake_openid`）。页面不调用，见 `doc/test-cases.md` |
